# AgentTools 4.1.0

Prepared 4.1.0 after Sam authorised merging [PR #17](https://github.com/elegantchaos/AgentTools/pull/17), publishing a release and installing it locally with Mint. The previous release is v4.0.1. A minor version fits the new `agt links` command; existing commands retain their interfaces.

The release adds Markdown link checking and historical-link repair, including the [review fixes](2026-11-17-pr17-review-fixes.md). Release notes were checked against `rt changes --start v4.0.1 --end HEAD`; the range contains only this feature and its review records. `RELEASE-NOTES.md` now describes 4.1.0.

Full local validation passed the macOS product build and all 321 tests in 46 suites at `068d54312e928917adeb790b7129ea762510fcae`. Targeted validation and formatting/linting passed too. All subsequent changes are Markdown-only, including this release preparation, so the existing full result covers the release's code. At preparation time, the Xcode 27 CI build had passed and the remaining four jobs were queued, with no reported failures.

The authorised sequence is to merge the PR, publish tag `v4.1.0` from the resulting main-branch merge commit with release title `4.1`, then run `mint install elegantchaos/AgentTools@v4.1.0`. The local installation is checked with `agt --version` and `agt links --help`; this does not change the VM guest installation or merge the companion Agents guidance PR.

# 2026-10-27

## Sandbox access to the Agents checkout

- A Bookish session had to leave its sandbox to fix shared guidance in `~/.local/share/agents`, because neither runtime's sandbox could write there. Sam had expected `agt sandbox configure` to cover it; it only allowed SwiftPM's cache and the clang module cache.
- `agt sandbox configure`, and so `agt refresh`, now also allows writes to the Agents checkout that maintenance commands use: `AGENTS_REPO_ROOT` when set, otherwise `~/.local/share/agents` ([0009](../Decisions/0009-agents-repository-defaults-to-the-shared-checkout.md)). The path is added whether or not the checkout exists yet, so configuring before cloning still works.
- `RepoRootLocator.configuredRoot` gives that path without validating it, and `locateRepoRoot` uses the same override and default, so the two cannot disagree.
- The new writable-path tests failed against a stub returning only the caches and passed with the change. `agt format` passed without lint findings; `agt validate --target AgentToolsCore` passed all 195 tests.
- `.worktrees/` is now ignored, since agent worktrees live there.

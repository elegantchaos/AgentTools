# 2026-10-27

## Sandbox access to the Agents checkout

- A Bookish session had to leave its sandbox to fix shared guidance in `~/.local/share/agents`, because neither runtime's sandbox could write there. Sam had expected `agt sandbox configure` to cover it; it only allowed SwiftPM's cache and the clang module cache.
- `agt sandbox configure`, and so `agt refresh`, now also allows writes to the Agents checkout that maintenance commands use: `AGENTS_REPO_ROOT` when set, otherwise `~/.local/share/agents` ([0009](../Decisions/0009-agents-repository-defaults-to-the-shared-checkout.md)). The path is added whether or not the checkout exists yet, so configuring before cloning still works.
- `RepoRootLocator.configuredRoot` gives that path without validating it, and `locateRepoRoot` uses the same override and default, so the two cannot disagree.
- The new writable-path tests failed against a stub returning only the caches and passed with the change. `agt format` passed without lint findings; `agt validate --target AgentToolsCore` passed all 195 tests.
- `.worktrees/` is now ignored, since agent worktrees live there.

## Sandbox access to the user temporary directory

- From 21 October, `agt validate` failed inside Claude Code's sandbox: Swift Build reported "unable to write manifest" with "Operation not permitted" for its `XCBuildData/…/manifest.json`, in main checkouts and worktrees alike. Bookish session transcripts show about 490 sandboxed runs passing up to Claude Code 2.1.299 (20 October), the first failure on 2.1.304 (21 October), and agents running `agt` outside the sandbox from then on without saying why.
- Cause: the save is atomic, and Foundation stages atomic writes in the per-user temporary directory (`getconf DARWIN_USER_TEMP_DIR`, under `/var/folders/…/T`), whatever `TMPDIR` says. Claude Code's sandbox sets `TMPDIR` to its own `/tmp/claude-<uid>` and does not allow the per-user directory. A plain write of the same file succeeds; an atomic write fails; `xcrun` fails writing its cache there too, on Xcode 27.1 as well as 27.2. The new Claude Code version presumably stopped allowing that directory; its earlier configuration was not available to confirm.
- `agt sandbox configure` now adds the per-user temporary directory beside the caches and the Agents checkout. The path comes from the user account, not the boot, so it is stable across restarts.
- The new path test failed against a stub that accepted the directory but did not add it, then passed. `agt format` passed without lint findings; `agt validate --target AgentToolsCore` passed all 196 tests.
- `Extras/Scripts/sandbox-check.sh` allows `TMPDIR`, which outside an agent is the per-user temporary directory, so it could not catch this. Making it mirror an agent's `TMPDIR` is left for later.

# AgentTools 4.0.0

Prepared the 4.0.0 release after Sam asked to cut it once PR #14 merged. The previous release is v3.15.0; the range adds PR #13, the lock release race fix, and PR #14, the paired-worktree validation modes.

The release is a major version because bare `agt validate` changes from full validation to change-scoped validation and `--fast` is removed, so existing callers change behaviour without an error. The `swift:validation` skill update is elegantchaos/Agents#45, which can merge once this release is installable.

The last code revision is `1b3b65a`, part of PR #14's head `4564be6`, whose full validation passed locally with 287 tests and whose CI passed on Swift 6.2, 6.3 and 6.4. Later changes, including this release preparation, are Markdown-only.

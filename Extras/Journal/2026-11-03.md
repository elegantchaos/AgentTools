# 2026-11-03

## Preparation skips packages validation never uses

`agt prepare` on Bookish resolved the four packages under `Extras/Legacy`. Discovery finds them, as it does for validation, and validation's package summary reports them as not part of the product.

The difference was in the plan: `PreparationPlan` added a SwiftPM resolve step for every discovered package, whereas validation only acts on packages in the product and not excluded by name. Preparation now applies the same filter. Packages outside the product can still be described by `agt validate --target` or `--fast` if changes touch them, but preparation no longer warms them.

Validation: `PreparationPlanTests` pass, including a new test for out-of-product and excluded packages. The targeted run had 11 unrelated failures in `WorktreeCreatorTests` and `RefreshTests` because the agent sandbox denies Git hook templates and process-group checks.

## Discovery skips Git-ignored paths

Bookish's `.gitignore` has listed `Extras/Legacy` since 2022, but commit `cac02e53` committed 17 files there anyway. Git does not treat tracked files as ignored, so a plain `git check-ignore` misreported them; `--no-index` matches the rule. About 3,200 files sit in that folder on disk.

Package discovery now drops any candidate file that a Git ignore rule matches, tracked or not, using one `git check-ignore --no-index` call per 200 paths after the walk. Outside a Git repository nothing is ignored. This applies to `packageDirectories` and `fingerprintFiles`, so both validation and preparation stop describing the legacy packages, and the discovery cache no longer depends on their manifests. The walk itself still enters ignored directories; only the few manifest and Xcode files it collects are checked.

A first version fed paths through standard input from a background writer. In fixtures without a Git repository, `git` exited before reading and the write raised SIGPIPE, killing the test process. Arguments avoid the pipe entirely.

Validation: format and lint clean. Targeted `AgentToolsTests`: 220 tests, including a new discovery test with a force-tracked ignored package; the only 11 issues are the sandbox-dependent `WorktreeCreatorTests` and `RefreshTests`.

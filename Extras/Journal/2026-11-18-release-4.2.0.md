# AgentTools 4.2.0

Prepared 4.2.0 after Sam asked to merge [PR #18](https://github.com/elegantchaos/AgentTools/pull/18), release it and update the local Mint installation. The previous release is v4.1.0. A minor version fits: `agt sandbox configure` gains behaviour, and no interface changes.

The release adds [Claude Code's sandbox exclusions](2026-11-18-claude-excluded-commands.md) for `agt` and `rt`. Full local validation passed the macOS product build and tests at `5022ef5`; this preparation changes only Markdown. On CI, the Swift 6.2 and 6.4 jobs and both Xcode jobs passed; the Swift 6.3 job was cancelled at its 15-minute limit with no test failure and no retained log, and was re-run before merging.

After merging, tag `v4.2.0` is published from the merge commit with release title `4.2`, then `mint install elegantchaos/AgentTools@v4.2.0` installs it locally and `agt refresh` applies the new Claude Code settings.

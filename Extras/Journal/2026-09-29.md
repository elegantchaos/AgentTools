# 2026-09-29

## `agt sandbox configure` and `agt refresh` (3.8.0)

- Sam wants every script the Agents repository needs to become an `agt` command, so that `agt` is its single dependency. Its two remaining maintenance scripts move here: `scripts/configure-sandboxes` (Python) becomes `agt sandbox configure`, and `scripts/refresh` (bash, with an identical copy in `.bin/refresh`) becomes `agt refresh`. `ensure-agt.sh` stays a shell script, since it installs `agt`. This is the promotion tier that [decision 0005](../Decisions/0005-agt-manages-agent-scripts.md) describes, for scripts that already had a stable interface.
- `agt sandbox configure` edits Codex's `config.toml` as text rather than parsing and rewriting it, because the file is the user's own and swift-configuration does not read TOML. It inserts entries into the existing array and leaves every other character alone. The Python script rewrote a single-line array with a regular expression and gave up on a multi-line one, which is the layout on Sam's machine; a copy of that pre-refresh config now gets exactly the line Sam added by hand. It also extends the root-table dotted key `sandbox_workspace_write.writable_roots`, the form the README's manual example uses, and adds a dotted key when other dotted keys define the table, since a `[sandbox_workspace_write]` header would then be invalid. It refuses an inline table, triple-quoted strings and non-string elements.
- Claude Code's `settings.json` is decoded and re-encoded with sorted keys. That can reorder the file the first time it changes, but it only writes when a path is missing, and it backs the file up first, as the Python script did.
- The user cache directory comes from `confstr(_CS_DARWIN_USER_CACHE_DIR)`, which is what `getconf DARWIN_USER_CACHE_DIR` prints, so there is no subprocess.
- `agt refresh` runs the same steps as the script. Neither `claude` nor `codex` was on `PATH` during the last refresh, which silently skipped plugin installation, so the runtime locator falls back to `~/.local/bin/claude` and the newest `~/Library/Application Support/Claude/claude-code/<version>/claude.app/Contents/MacOS/claude` for Claude Code, and to `/opt/homebrew/bin`, `/usr/local/bin` and the ChatGPT app's `Contents/Resources/codex-cli/bin/codex` for Codex. It does not update `agt` itself, which the running binary cannot do; the `baseline:refresh` skill runs `ensure-agt.sh --update` first.
- New `AgentRuntime` enum holds each runtime's name and home directory override (`CODEX_HOME`, `CLAUDE_CONFIG_DIR`); `SkillLinkDestination` now uses it too.
- Checked end to end: `agt refresh` from the Agents repository produced the same skills, sandbox and plugin results as `scripts/refresh`.

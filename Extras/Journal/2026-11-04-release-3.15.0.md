# AgentTools 3.15.0

Prepared the 3.15.0 release from PR #12 after Sam authorised its merge, publication and local Mint update. The previous release is v3.14.0. This minor release adds `agt vm` and makes `agt ui press` focus text fields, as recorded in the [implementation journal](2026-11-04-vm-commands.md) and [0011](../Decisions/0011-agt-vm-only-touches-its-own-clones.md).

The last code revision is `9e9b279`, whose full validation passed locally with 274 tests. Later changes, including this release preparation, are Markdown-only. RELEASE-NOTES.md had no 3.14.0 entry, so one was added from the [2026-11-03](2026-11-03.md) and [UI driving](2026-11-04-ui-driving.md) entries. Sam chose to merge without waiting for CI, whose runs sat queued; local full validation of `9e9b279` stands in, and CI is to be checked afterwards.

Installing the release changes `agt`'s code hash, so the host's calendar permission needs granting again on first use. The guest's `/usr/local/bin/agt` in `golden-gate` stays at its granted 3.14.0 build; `agt vm` drives it unchanged, but `press` focusing needs the new build in the guest, with its grants given again.

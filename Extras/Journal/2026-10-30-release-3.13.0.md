# AgentTools 3.13.0

Prepared the 3.13.0 release from PR #9 after Sam authorised its merge, publication and local Mint update. The previous published release is v3.12.0. This minor release moves calendar permission requests into the queries, removes `agt calendar authorize`, adds `--no-prompt`, and adds the request timeout, parent-exit watch and link replacement recorded in the [implementation journal](2026-10-30-calendar-access-diagnostics.md). RELEASE-NOTES.md now names the release.

The last code revision is `9024ddc`. Later changes, including this release preparation, are Markdown-only. Publishing uses the merged main commit, and Mint then installs that tagged version locally.

Installing the release changes the code hash of `agt`, so its first calendar query will ask for permission again. The companion Agents #40 remains a separate merge: this release supplies its prerequisite, and its "AgentTools 3.9 or later" line still needs raising to this version.
